# MapZa geographic database

Complete derived city catalogs used by MapZa, distributed under the Open Database Licence 1.0 (ODbL).

[Download versioned geographic releases](https://github.com/scampbell31/mapza-geography/releases)

The current catalog has 12,593 cities. Each catalog ZIP includes the entire machine-readable derived database, licence, attribution and source/checksum provenance. Catalog-specific downloads remain available for historical challenges.

The source is Countries States Cities Database by Darshan Gada and contributors (ODbL 1.0); QRank annotations are CC0-1.0. Each archive records exact source revisions and hashes.

These releases satisfy the full derivative-database distribution route in ODbL section 4.6(a). Application software, player accounts, profiles, guesses, results and telemetry are separate and are never included.
